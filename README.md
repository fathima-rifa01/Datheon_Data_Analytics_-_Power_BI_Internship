# Datheon Data Analytics & Power BI Internship

## Overview

This repository contains completed projects from my **Data Analytics and Power BI Internship at Datheon**. The projects focus on exploratory sales analysis using Python and the development of an interactive executive sales and profit dashboard using Microsoft Power BI.

The objective is to transform raw sales data into meaningful business insights and interactive visualizations that support data-driven decision-making.

## Projects

### Task 01: Exploratory Sales Analysis – Superstore Sales

**Objective:** Analyze customer purchasing behavior, sales trends, category performance, and discount sensitivity to identify actionable business insights.

**Tools & Technologies:**
- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

**Key Activities:**
- Data cleaning and preprocessing
- Handling missing values
- Order date processing and Year-Month extraction
- Customer purchase volume analysis
- Monthly sales trend and seasonality analysis
- Category, regional, and customer segment performance analysis
- Discount versus profit analysis
- Business insight generation

**Deliverables:**
- Python analysis notebook
- Data visualizations
- Executive business takeaways

### Task 02: Interactive Power BI Executive Sales & Profit Dashboard

**Objective:** Develop an interactive executive dashboard to monitor sales performance, profitability, and regional business trends.

**Tools & Technologies:**
- Microsoft Power BI Desktop
- Power Query
- DAX

**Key Features:**
- Sales, Profit, and Orders KPI cards
- Profit Margin and Year-over-Year Sales Growth measures
- Monthly sales trend visualization
- Category and Sub-Category performance treemap
- Regional sales and profit analysis
- Interactive date and region slicers
- Product profitability analysis

**Deliverables:**
- Power BI dashboard (.pbix)
- PDF dashboard report
- Dashboard screenshots
